- [`nimbu help [COMMAND]`](#nimbu-help-command)

## `nimbu help [COMMAND]`

Display help for nimbu.

```
USAGE
  $ nimbu help [COMMAND] [-n]

ARGUMENTS
  COMMAND  Command to show help for.

FLAGS
  -n, --nested-commands  Include all nested commands in the output.

DESCRIPTION
  Display help for nimbu.
```
